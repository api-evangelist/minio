 S3 API Capabilities

 Full API Coverage
 Complete S3 API implementation including object operations, bucket policies, versioning, lifecycle management, and multipart uploads.
 IAM Integration
 Native support for IAM policies, roles, STS credentials, and OIDC federation for unified identity and access management.
 Advanced Security
