# MinIO

> MinIO is a high-performance, S3-compatible object storage system for large-scale AI, analytics, and cloud-native data infrastructure. It implements the Amazon S3 REST API (buckets, objects, multipart uploads, versioning, object locking/WORM, lifecycle, replication, encryption) authenticated with AWS Signature Version 4, plus an Admin API for cluster, user, and policy management. Distributed as open-source software and the commercial AIStor product.

## APIs
- [S3-Compatible API](https://min.io/product/s3-compatibility): Drop-in Amazon S3 REST API for object storage.
- [Admin API (madmin)](https://github.com/minio/madmin-go): Cluster, user, group, policy, and service management.
